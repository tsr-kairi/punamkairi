## 🌟 Key Features

- **📱 Mobile-First Native App Experience**: Optimized touch interactions, horizontal category swipe bar, compact luxury service cards, and bottom dock bar.
- **✨ Cinematic Auto-Sliding Hero**: Side-by-side content and portrait layout with 4 curated themes (Punam Kairi Artist Spotlight, Durga Puja Festive Special, Royal Bridal, and Evening Glamour).
- **📋 Full Digital Artistry Menu**: 14+ services including:
  - **Bridal Artistry** (Royal Signature Bridal, HD 4K Camera-Ready, Luxury Airbrush)
  - **Wedding Ceremonies** (Engagement, Reception & Evening Gala, Haldi & Sangeet)
  - **Party & Festive** (Red Carpet Glam, Traditional Regional, Soft Glam)
  - **Facials & Skin Glow** (24K Gold Luxury Radiance, Diamond Anti-Tan, Hydra-Dew Glass Skin, O3+ Vitamin-C, Organic Herbal, Express Polishing)
  - **Threading & Grooming** (Precision Eyebrow Architecture, Upper Lip, Full Face Peach Fuzz, Forehead, Rose Pack Combo)
  - **Specialized & Editorial** (Studio Fashion, Signature Cut-Crease)
- **🌸 Durga Puja & Grand Launch Festive Suite**: Top announcement banner, floating festive badge, interactive festive discount modal.
- **💬 Direct WhatsApp Booking Engine**: Auto-formatted booking messages with selected service, preferred dates, location, and guest requirements directly to `+91 6003756297`.
- **📲 QR-Code Pass Engine**: Printable and scannable QR code generator linking directly to the instant Digital Menu (`/?view=menu`).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS (Dark Luxury Gold & Obsidian Palette)
- **Animations**: Framer Motion & Lucide Icons
- **Deployment Ready**: Static SPA build for Vercel / Netlify / GitHub Pages / Cloudflare Pages

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
